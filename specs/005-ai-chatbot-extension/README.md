# AI-Powered Todo Chatbot Extension

This feature adds an AI-powered conversational chatbot interface to the existing Todo application, allowing users to manage tasks using natural language commands.

## Overview
- Natural language task management interface
- OpenAI ChatKit and Agents SDK integration
- MCP tool-based backend interaction
- Maintains user authentication and data isolation
